## How I work

1. Start with the business problem and define a clear scope.
2. Build in small, testable, maintainable increments.
3. Use AI to accelerate research and execution, with human review at every critical point.
4. Validate the real user flow before calling the work complete.
5. Document decisions so the next person can move faster.
